# Fortnite Booster PRO

A Windows 11 x64 Fortnite-only desktop launcher with an Epic Games Store-inspired dark library interface.

## Current version
- One featured title: Fortnite.
- Official Fortnite artwork is downloaded from Epic's CDN and cached locally.
- Large featured hero panel, library tile, search, Play, Epic Store and game-path controls.
- Safe user-level Game Mode / Game DVR profile in the BOOST panel.

## Build
GitHub Actions builds a self-contained single-file Windows executable on every push to `main`.
Open **Actions**, choose the newest successful **Build Windows EXE** run, and download the `FortniteBoosterPRO-Windows-x64` artifact.
