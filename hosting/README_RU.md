# Размещение обновлений Fortnite Booster PRO

Лаунчер проверяет обновления по HTTPS-файлу `manifest.json`. Подойдёт любой статический хостинг, который отдаёт файлы напрямую по HTTPS (например, собственный сайт, Cloudflare Pages, GitHub Pages для публичного репозитория или объектное хранилище).

## Структура на хостинге

```
/updates/
  manifest.json
  /downloads/
    FortniteBoosterPRO.exe
```

## Настройка

1. Скачай готовый `FortniteBoosterPRO.exe` из артефактов GitHub Actions.
2. Загрузи EXE на свой хостинг.
3. Посчитай SHA-256 файла в PowerShell:

   ```powershell
   (Get-FileHash .\FortniteBoosterPRO.exe -Algorithm SHA256).Hash
   ```

4. Скопируй `hosting/update-manifest.example.json` в `manifest.json`.
5. Укажи новую версию, HTTPS-ссылку на EXE и полученный SHA-256.
6. В лаунчере открой **Настройки** и вставь HTTPS-ссылку на `manifest.json`.

После этого Booster проверяет обновления при запуске и далее раз в 6 часов. Если найдена новая версия, файл автоматически скачивается и проверяется по SHA-256. Установка выполняется после нажатия «Установить и перезапустить», чтобы не закрывать игру или работу пользователя неожиданно.

Важно: для каждой новой версии повышай `version` в формате `major.minor.patch`, загружай новый EXE и обновляй SHA-256 в манифесте. Сервер должен разрешать GET-запросы и отдавать JSON с корректным `Content-Type`.
